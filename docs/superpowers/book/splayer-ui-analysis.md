# SPlayer UI 设计分析

> 参考仓库：github.com/imsyy/SPlayer（Vue 3 + TypeScript + Naive UI + Electron，6K+ Star）
> 版本：v3.0.0-beta.9 (2025)

## 整体气质

SPlayer 的界面是一个 **有壁纸氛围的、半透明材质的、桌面级音乐工作台**。视觉上：
- 不像是"网页"，更像一个精致的桌面 App
- 壁纸+暗层+半透明面板三层结构
- 字体、间距、曲率都是经过精心调校的
- 所有交互控件都像是悬浮在壁纸上，而不是嵌在页面里

用户感受最深的点：壁纸氛围在动，面板是"浮"着的，输入控件的焦点环有细微发光，一切都很柔和不硬。

## 核心设计体系

### 1. 三层视觉结构

```
┌── Wallpaper Layer ─────────────────┐
│  固定定位的背景图/视频               │
│  支持 blur / scale / mask 调节       │
│  z-index: 0                        │
├── Ambient Overlay ─────────────────┤
│  暗化蒙层，确保文字可读               │
│  半透明黑色 / 跟随主题色染色          │
│  z-index: 1                        │
├── App Shell ───────────────────────┤
│  实际交互容器                        │
│  z-index: 2                        │
└────────────────────────────────────┘
```

### 2. backdrop-filter 玻璃态

SPlayer 的"半透明"并不是每个组件都做 blur，而是：
- **主播放器栏**：`backdrop-filter: blur()` — 底部固定条
- **弹出层/模态框**：`.n-modal`, `.n-popover` — 弹出的面板
- **侧栏**：有 blur，但文字始终保持完全不透明
- **内容卡片**：不是全部 blur，而是 `rgba(var(--background), 0.2~0.5)` 半透明底，**不加 blur**
- **正文区域**：不做任何透明度处理，保证可读

关键规则：**blur 只用在大块固定面板上，小卡片只用半透明色底 + 细边框，正文永远不透明。**

### 3. 颜色系统

```
后台提取流程：
  封面图片加载 → QuantizerCelebi 像素量化 → 评分排序 → 
  Material Design 3 调色板生成 → CSS 变量注入 document.body

CSS 变量体系：
  --primary          // 主色（按钮、选中态、焦点）
  --background       // 背景色（RGB 分量，用于 rgba() 构造）
  --surface          // 表面色
  --surface-container // 容器色
  --on-primary       // 主色上的文字
  --outline          // 边框
  --background-hex   // 背景 Hex 值（用于回退）
  --surface-container-hex
```

OhMyWu 当前只有 `--accent` 一个变量，缺少完整色板。至少需要：
- `--accent` — 主色
- `--accent-soft` — 软主色（选中/悬浮底）
- `--surface-bg` — 面板背景
- `--surface-border` — 面板边框
- `--surface-high` — 更高层的面板

### 4. 边框处理

SPlayer 的边框非常克制：
- 不是用纯白或纯黑色边框
- 而是 `rgba(255,255,255, 0.06~0.10)` 的细线
- 有层级时用稍亮的边框区分内外
- 元素有 focus 或 hover 时，边框变亮 + 微微发光

### 5. 壁纸背景系统

SPlayer 支持用户自定义图片或视频作为背景，并调节：
- 缩放 scale
- 模糊 blur
- 遮罩不透明度 mask-opacity

我们的首轮用 CSS 渐变是合理的（不引入资源管理），但当前渐变太简陋。需要升级为更有氛围感的渐变组合，更像"壁纸"。

### 6. 排版与间距

- 字体权重明确：标题 700，正文 400-500，辅助文字 400
- 字号梯级干净：11/12.5/13.5/15/18/22
- 间距统一：4/8/12/16/20/24/32
- 圆角统一：4/6/8/12/16
- 行高一致：正文 1.6，代码 1.5

## OhMyWu 当前问题对照

| 维度 | SPlayer 做法 | OhMyWu 当前 | 差距 |
|------|-------------|------------|------|
| 壁纸 | 渐变/图片/视频，可调参数 | 4 个简陋线性渐变 | 渐变无质感，像 demo |
| 透明度 | 只在大面板+弹出层 blur，卡片只用半透明色 | 到处 blur | 过度模糊，性能差且丑 |
| 颜色 | Material 3 完整色板 | 只有 --accent | 缺少 surface/outline/soft 色板 |
| 边框 | rgba 细线 0.06-0.10 | 直接用了 --surface-border | border 太亮太硬 |
| 字体 | 有性格的字体 | Inter | AI slop 字体 |
| 氛围 | 壁纸→环境蒙层→面板→内容，层次分明 | 一层 blur 完事 | 没层次感 |
| 动画 | 页面加载渐入、hover 过渡 | 部分动画 | 缺少入场动画 |

## 改进方向

1. **壁纸升级**：不用简陋的纯色渐变，改用多色点渐变 + 噪点纹理，模拟更真实的"壁纸氛围"
2. **透明度分层**：blur 只给侧栏、底栏、右侧抽屉、弹出层；卡片只做半透明底不加 blur
3. **色板扩展**：基于 accent 推导 surface/outline/soft/glow 系统
4. **边框收口**：统一用 rgba(255,255,255, 0.06-0.10) 细线，hover 时调到 0.12-0.15
5. **字体升级**：换掉 Inter，用更有性格的字体组合
6. **入场动画**：页面加载时侧栏/主内容区有错落入场
7. **壁纸可调**：壁纸选择保留，但预置壁纸做得更像壁纸，每个包含多色点+纹理
